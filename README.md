# COVID-19 STATE-WISE DASHBOARD 2020

## 📌 Project Overview
An interactive Power BI dashboard analyzing COVID-19 cases across Indian states and union territories in 2020. It visualizes confirmed, recovered, active, and death cases through charts, maps, and slicers.

## 🎯 Objectives
- Analyze state-wise COVID-19 cases.
- Track monthly trends and recovery rates.
- Compare cases across states and union territories.
- Build an interactive dashboard using Power BI.

## 🛠️ Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX
- Microsoft Excel / CSV

## 📊 Dashboard Pages
**1. Summary Dashboard**
- KPI cards for confirmed, resolved, active, and death cases.
- Monthly and day-of-week filters.
- COVID-19 trend analysis.

**2. Overview Dashboard**
- State-wise map visualization.
- Monthly and day-wise trends.
- Treemap and state comparisons.

## ✨ Key Features
- Interactive slicers and filters.
- KPI cards and multiple visualizations.
- Two-page dashboard navigation.
- State-wise and monthly analysis.

## 🗂️ Dataset
The dataset contains date, state, confirmed cases, recovered cases, and deaths. Additional columns were created using Power Query and DAX.

**Note:** The dataset includes simulated sample records. Results are for learning and demonstration purposes and may not represent official historical statistics.

## 🚀 How to Use
1. Download or clone this repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Refresh the data source if required.
4. Explore the dashboard using slicers and filters.

## 📚 Learning Outcomes
Practised data cleaning, calculated columns, DAX, data visualization, KPI cards, and interactive dashboard development.
